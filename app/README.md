# App - Balbina Agro V1

Pasta para arquivos auxiliares do app, exemplos de payload, materiais de teste e artefatos operacionais que nao pertencem diretamente ao backend ou frontend.

## Estrutura atual

```text
app/
└── examples/
    └── abrir-lote-request.json
```

## Observacao sobre Android

O projeto Android nativo fica em:

```text
frontend/android
```

Ele permanece dentro de `frontend/` porque foi gerado pelo Capacitor e os comandos `npx cap sync android` esperam essa estrutura.
